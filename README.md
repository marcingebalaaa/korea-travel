# KoreaTravel - Przewodnik po Korei Południowej

# O projekcie
KoreaTravel to responsywna strona internetowa pełniąca rolę przewodnika po Korei Południowej. Strona zawiera interaktywną galerię zdjęć, rozwijane menu mobilne oraz w pełni funkcjonalny tryb ciemny.
Została wyknana w ramach pracy domowej z laboratoriów Aplikacji internetowytch.

# Link do opublikowanej strony
https://marcingebalaaa.github.io/korea-travel/

# Wykorzystane technologie
HTML5: semantyczna struktura strony
CSS3: stylowanie (Flexbox, CSS Grid), responsywność (Media Queries)
JavaScript: obsługa trybu ciemnego, powiększanie zdjęć (popup), obsługa mobilnego menu (hamburger)
